# web-project


Book Store website


## Description
An e-commerce platform for selling a variety of books. Users can browse books, categorize them, add to the cart, and purchase them. Admins have special privileges to manage the book inventory.

## Features
- Book display and categorization
- Add to cart and checkout functionality
- Secure user and admin registration based on email forms
- Admin dashboard for adding or editing books

## Setup Instructions
1. Clone the repository.
2. Install dependencies using `npm install`.
3. Configure the database in the `.env` file.
4. Start the server with `npm start`.

## Usage
- Browse the homepage for available books.
- Use the category filter to find books by genre.
- Add books to the cart and proceed to checkout.
- Admins can log in and manage the book inventory.
